# mtl5_bench coverage manifest (#721 M7).
#
# Every public header in the directories named by a `scan` line must have a
# line here, and every line here must name a header that exists. That is what
# keeps "the benchmark covers ALL of MTL5" true as the library grows: adding an
# operation header without saying how it is measured fails CI
# (benchmarks/check_coverage.sh, run in the benchmarks lane).
#
# Line format:  <header under include/mtl>  <kind>  <target>
#
#   bench   an entry calls this header's operation directly. <target> is an
#           entry-name prefix that must match at least one line of
#           `mtl5_bench --list` (area/op/dtype).
#   via     the operation is measured inside the entry named, which calls it
#           (lower_trisolve inside trsv, restriction inside the V-cycle, ...).
#           <target> must match a --list line, as for bench.
#   class   not called by the entry named, but the same kernel class: the same
#           loop shape and the same roofline (exp2 against exp, cos against
#           sin). <target> must match a --list line. Use it only where a
#           separate entry would add a row to the card and no information.
#   exempt  not measured. <target> is the reason, which is required. Exempt
#           headers are queries, I/O, umbrellas, type plumbing and predicates:
#           nothing whose rate characterizes a machine.
#
# A `#` starts a comment, so a note can follow any line.
